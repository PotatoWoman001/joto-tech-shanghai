## Cisco 页面结构基准

## 全站统一规则

- 页面结构完全复制 Cisco；只按厂商改内容，不为其他厂商另起一套结构。
- 绿色标题只表达客户结果，不再使用“由 JOTO 交付”“JOTO 为您提供”等供应商视角句式。
- 首屏短介绍控制在 60–100 个汉字，先说明适用环境和业务价值，再说明 JOTO 的角色。
- Cisco 页面全部保持现状，不修改标题、介绍、合作价值、服务、CTA 或现有三个代表项目。
- 除 Cisco 外，其他 19 页的第 `04` 板块统一为“代表项目”并暂时留空，不预写客户、案例、应用场景或项目成果。

- JOTO 相关服务文字表示本页拟呈现的服务范围；除老官网有直接证据的内容外，发布前仍需对应 Solution Owner 内部确认。
