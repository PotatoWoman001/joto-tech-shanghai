# “What We Deliver” 大图卡片改版设计

## 目标

将首页 “What We Deliver” 五项解决方案从紧凑信息格重做为参考图风格的大图卡片。卡片以真实项目场景为视觉主体，默认状态简洁，悬停状态通过纵向展开呈现一句话说明与行动按钮。

## 版式

- 桌面端采用三列网格，五张卡片按 3 + 2 排列；第二行两张卡片保持与第一行相同宽度。
- 平板端采用两列，手机端采用单列。
- 卡片使用明亮的大幅竖向摄影图片、圆角和充足留白。
- 默认状态下，图片区域展示分类标题；描边胶囊按钮位于图片下方。
- 每张卡片保留现有本地化标题，并将现有说明压缩为一句简短说明。

## 交互

- 桌面端悬停或键盘聚焦时，图片区域向下平滑展开。
- 图片在展开过程中轻微放大，并叠加自下而上的渐变以保障文字可读性。
- 一句话说明淡入并上移，描边按钮同步收进图片底部并变为黑底白字。
- 箭头轻微向右移动，强化可点击反馈。
- 鼠标移出或焦点离开后恢复默认状态。
- 手机与不支持悬停的设备不依赖悬停：一句话说明和按钮保持可见，确保触屏可用。
- 遵循 `prefers-reduced-motion`，减少动态偏好下关闭尺寸、位移和缩放动画。

## 导航与可访问性

- 每张卡片链接到对应的解决方案锚点/入口，按钮文案随语言显示 “Learn more / 了解更多 / بیشتر بدانید”。
- 整张卡片具备一致的键盘焦点反馈，按钮使用清晰的可访问名称。
- 图片保留对应语言的替代文本。

## 图片方向

统一生成五张无文字、无品牌标识、无水印的企业项目现场摄影：

1. Network：现代办公园区或数据中心的网络基础设施，真实布线与设备环境。
2. Security：企业安全运营中心或监控环境，真实屏幕与协作场景。
3. Server & Storage：明亮、整洁的数据中心通道与服务器机柜。
4. Collaboration：现代会议空间中的企业协作与音视频系统。
5. Safeguarding：现代园区入口、门禁、视频监控或安全管理场景。

五张图保持统一的自然光、建筑摄影质感、克制的中性色和轻微绿色调，避免当前偏概念渲染、过暗或蓝色科技感过强的问题。

## 验证

- 为卡片结构、链接、简短说明和多语言按钮补充组件测试。
- 执行完整测试与 Sites 构建。
- 在实时预览中检查桌面默认态、悬停态以及手机单列布局。
