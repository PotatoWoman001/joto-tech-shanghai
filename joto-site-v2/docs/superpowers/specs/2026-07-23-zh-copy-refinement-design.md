# 中文站文案润色设计

## 目标

在不改变服务范围、项目事实和品牌定位的前提下，降低中文站的直译感和模板化表达，使文案更接近专业技术服务公司的真实沟通方式。同时将 IT 采购服务从“服务在华跨国企业”调整为面向全球业务，并同步更新中文、英文和波斯语。

## 文案原则

- 标题直接表达能力、范围或结果，不使用“全程相伴”“赋能”“打造”等泛化口号。
- 正文优先说明 JOTO 做什么、负责到什么阶段、为客户解决什么问题。
- 保留 Cisco、SLA、SOC、ITIL 等行业术语，不用宽泛词替代准确概念。
- 项目事实、客户名称、数字、地点和已披露范围保持不变。
- 中文使用自然的企业级 B2B 语气；IT 采购的英文和波斯语只调整地域范围，不扩大服务内容。

## 重点改写

- “让基础设施成为一个互联整体。”改为“让各类基础设施协同运转。”
- “从首次研讨到稳定运营，全程相伴。”改为“覆盖规划、实施与长期运维。”
- “精选经验”改为“项目案例”；“复杂环境，也能稳妥交付。”改为“复杂项目，可靠交付。”
- IT 采购改为面向全球业务的一站式硬件、软件与云服务采购。

## 验收标准

- 中文首页、关于页、联系页和解决方案详情页不再出现明显直译或模板化标题。
- 三种语言的 IT 采购文案均不再限定“在华”或“中国市场”。
- 页面结构、路由和组件行为不变。
- 类型检查、自动化测试和生产构建通过；中文页面无横向溢出。
