# 中文首页 About 指标字号调整

## 目标

降低中文首页 “选择 JOTO” 右侧四个绿色指标的视觉重量，同时保持英文和波斯语现有样式不变。

## 已确认设计

- 仅当当前语言为 `zh-CN` 时，为四个指标值使用 `clamp(2.1rem, 3.25vw, 3.25rem)`。
- 英文与波斯语继续使用现有的按文本长度分级字号。
- 不修改卡片尺寸、间距、颜色、动效与文字内容。
- 中文四个指标继续保持单行，不产生横向溢出。

## 验收标准

- `/zh/` 的 `2010`、`5`、`多厂商`、`全生命周期` 视觉尺寸一致且明显小于当前版本。
- `/` 与 `/fa/` 的指标字号类保持原样。
- 测试、生产构建与线上中文页面检查通过。
