# Hero 主按钮三语固定间距设计

## 目标

恢复首页 Hero 桌面端“第二行标题绿点 + 主按钮”的同一行组合，并以英文当前视觉距离为基准，将英文、中文和波斯语的绿点到按钮间距统一为约 `64px`。移动端继续将按钮放在说明文字下方。

本设计取代同日“按钮按语言百分比定位”和“所有尺寸均放在说明文字下方”两种方案。

## 布局规则

- 桌面端从 `lg` 断点开始，主按钮与第二行标题保持同一视觉行。
- 按钮与第二行标题之间使用统一的固定间距，不再使用语言专属百分比偏移。
- 英文、中文遵循 LTR：按钮位于绿点右侧。
- 波斯语继承 RTL：按钮位于绿点左侧。
- 约 `64px` 的间距以标题文本的实际宽度为基准，因此标题字数、字体或字宽变化时不会改变按钮与绿点的距离。
- 小于 `lg` 断点时，桌面按钮隐藏，说明文字下方的移动端按钮显示。

## 实现方式

- 保留桌面端与移动端两个响应式 CTA 实例，二者继续复用同一个 `HeroCta` 组件、文案、链接和交互样式。
- 调整桌面标题区域的结构，使第二行标题和桌面 CTA 由同一个支持 RTL/LTR 的布局容器管理。
- 使用 Tailwind 的逻辑方向与 `gap`/固定间距类表达布局关系，不增加 JavaScript 测量，也不维护中文、英文、波斯语三套水平百分比。
- 保留标题的完整无障碍名称以及按钮独立的链接语义。

## 实现边界

- 只修改首页 `Hero` 的 CTA 布局及相应测试。
- 不修改三语文案、按钮尺寸、字体、颜色、动画、链接、Hero 背景或其他区块。
- 不覆盖 `SolutionCategoryPage` 等工作区中的其他未提交改动。

## 验收标准

- 英文桌面端的现有绿点—按钮视觉距离保持约 `64px`。
- 中文桌面端的按钮不再紧贴绿点，间距与英文一致。
- 波斯语桌面端的按钮不再远离绿点，间距与英文一致，且阅读方向正确。
- 三种语言的标题与按钮无重叠、截断或视口溢出。
- 移动端按钮继续位于说明文字下方。
- 三种语言的 CTA 均继续链接到 `#solutions`，悬停与键盘焦点样式不变。

## 验证

- 更新组件测试，验证桌面端使用统一间距布局、移动端使用说明文字下方 CTA，且不再包含语言专属水平偏移。
- 运行相关测试、全量测试和生产构建。
- 在真实浏览器中以同一桌面视口检查 `/`、`/zh/`、`/fa/`，测量绿点与按钮边界间距并截图对照。
- 抽查移动端三种语言，确认响应式回退布局未受影响。
