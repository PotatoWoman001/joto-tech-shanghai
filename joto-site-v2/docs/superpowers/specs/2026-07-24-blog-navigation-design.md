# Blog 全站导航统一设计

## 目标

让 Blog 列表页与所有 Blog 文章详情页始终显示和站内其他内页一致的固定顶部导航，使用户可直接返回首页、进入其他栏目、切换语言或打开移动端菜单。

## 方案

- 复用现有 `Header` 组件，不创建 Blog 专用导航。
- 在 `BlogPage` 顶部渲染 `Header`；`BlogArticlePage` 保留现有 `Header`。
- 沿用 `Header` 已有的内页链接转换逻辑，使首页锚点、Blog、About、Contact、语言路径以及移动端菜单行为保持一致。
- 不改动 Blog 内容、文章版式、导航视觉样式或其他页面结构。

## 验证

- 组件测试覆盖 Blog 列表页和文章详情页均存在主导航。
- 验证中英文 Blog URL 的导航链接正确。
- 本地浏览器检查桌面端与移动端：导航可见、固定在顶部，JOTO 标志可返回当前语言首页，移动菜单可打开。
