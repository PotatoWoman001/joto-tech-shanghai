# 固定导航栏设计

## 目标

让首页及内页的导航栏在桌面端和移动端向下滚动时始终固定在视口顶部，用户无需返回页面顶部即可访问导航。

## 已确认方案

- 将 `Header` 的定位从 `absolute` 改为 `fixed`。
- 保持现有高度、菜单内容、语言切换、下拉菜单和移动端全屏菜单逻辑不变。
- 使用深色半透明背景和轻度背景模糊，确保导航经过不同页面内容时仍清晰可读。
- 保持现有边框和层级关系，桌面端解决方案下拉菜单及移动端菜单继续覆盖页面内容。
- 不修改首屏视频、背景亮度、动画或其他视觉内容。

## 验收标准

1. 在中文、英文和波斯文页面向下滚动后，导航栏仍位于视口顶部。
2. 页面滚动时导航文字、Logo 和语言切换保持清晰。
3. 桌面端解决方案下拉菜单可正常打开和点击。
4. 移动端菜单可正常打开、滚动和关闭。
5. 首屏背景及页面内容的颜色、亮度和动画保持不变。

## 验证方式

- 运行现有自动化测试和生产构建。
- 在桌面视口向下滚动，检查导航位置和下拉菜单。
- 在移动端视口向下滚动，检查导航位置和全屏菜单。
