# 系统语言路由设计

**日期：** 2026-07-24

## 目标

访客打开不带语言前缀的 JOTO TECH 网址时，网站应根据浏览器上报的系统首选语言选择受支持的语言。过去访问过某个本地化网址，不应让之后的普通访问被永久锁定为该语言。

## 支持的语言映射

- 中文浏览器语言（`zh` 和 `zh-*`）映射为 `zh-CN`。
- 波斯语浏览器语言（`fa` 和 `fa-*`）映射为 `fa-IR`。
- 英语及其他所有浏览器语言映射为 `en`。

浏览器通过 `navigator.languages` 和 `navigator.language` 提供这一偏好。网页无法脱离浏览器，直接、独立地读取操作系统语言。

## 路由优先级

1. 明确的本地化路径优先：
   - `/zh` 和 `/zh/*` 显示中文。
   - `/fa` 和 `/fa/*` 显示波斯语。
2. 对于不带语言前缀的路径，如果当前浏览器标签页中存在用户手动选择的语言，则优先使用该选择。
3. 否则，根据浏览器语言映射解析不带前缀的路径。

这样既能保留可分享的本地化链接，也能确保通过 `https://jotoglobal.com/` 正常进入网站时，从访客自己的语言开始。

## 偏好的有效期

现有的永久 `localStorage` 偏好（`joto:locale`）不再参与路由判断，并在语言提供器初始化时移除。

手动语言选择改用 `sessionStorage`，作用域限定在当前浏览器标签页。这样访客手动切换语言后可以继续浏览多个页面，不会在每次跳转时被立刻切回系统语言。关闭标签页后，手动覆盖失效；之后重新正常访问时，网站会再次识别浏览器语言。

如果浏览器不允许使用存储，明确的本地化路径仍然有效，不带前缀的路径则回退到浏览器语言识别。

## 组件职责

### `src/i18n/routing.ts`

- 保持浏览器语言映射结果稳定、可预测。
- 用仅限当前会话的手动覆盖键替换永久偏好约定。
- 保持明确路径解析和本地化网址生成规则不变。

### `src/i18n/I18nProvider.tsx`

- 尊重明确的 `/zh` 和 `/fa` 路径，但不再因此写入永久偏好。
- 在不带前缀的路径上，先读取当前标签页的手动覆盖，再识别浏览器语言。
- 删除旧的 `joto:locale` 值，避免历史访问影响新逻辑。
- 仅当解析后的目标语言需要不同路径时执行重定向。

### `src/components/LanguageSelector.tsx`

- 在跳转前，将用户主动选择的语言写入 `sessionStorage`。
- 保持现有本地化链接和菜单交互不变。

## 数据流

处理不带前缀的访问时：

1. 读取并移除旧的永久语言值。
2. 读取当前标签页的手动语言覆盖。
3. 如果没有手动覆盖，读取 `navigator.languages`；不可用时回退到 `navigator.language`。
4. 中文映射到 `/zh`，波斯语映射到 `/fa`，其他语言使用不带前缀的英文路径。
5. 仅当目标地址与当前地址不同时重定向。

处理明确的 `/zh` 或 `/fa` 访问时，立即显示对应语言并跳过自动识别。

## 验证

自动化测试覆盖：

- 中文浏览器语言将不带前缀的网址重定向到 `/zh`。
- 波斯语浏览器语言将不带前缀的网址重定向到 `/fa`。
- 英语及不支持的浏览器语言保留在英文路径。
- 旧的中文 `localStorage` 值不会覆盖英文浏览器语言。
- 明确的 `/zh` 和 `/fa` 网址优先于浏览器语言识别。
- 当前标签页中的手动选择在后续导航中保持优先。
- 浏览器存储不可用时仍能安全运行。
- 语言选择器只写入会话级手动覆盖。
