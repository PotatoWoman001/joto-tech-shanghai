# 三语言首页主视觉按钮位置设计

## 目标

将首页“查看解决方案”按钮移到用户标注的主标题旁边空档，使按钮与大标题形成一个视觉组合。

## 位置规则

- 英文桌面端：按钮放在第二行 `Happen.` 右侧空档。
- 中文桌面端：按钮放在“真正发生。”右侧空档。
- 波斯语桌面端：按照 RTL 阅读方向，按钮放在第二行标题左侧空档。
- 小于桌面断点时：按钮继续放在说明文字下方，避免遮挡标题或缩窄正文。

## 实现方式

在主标题外增加相对定位容器。桌面按钮以绝对定位放在该容器内，并通过语言专属的水平位置类对齐三个标注点；移动端保留当前文案列中的按钮。两个按钮使用同一文案、链接和视觉样式，仅通过响应式显示类保证任一视口只显示一个。

不改变主标题文字、动态词、说明文案、背景、信息卡或 CTA 样式。

## 验证

- 英文与中文桌面按钮使用标题容器约 `47%` 的水平位置。
- 波斯语桌面按钮使用标题容器约 `32%` 的水平位置。
- 桌面按钮隐藏于移动端，移动按钮隐藏于桌面端。
- 三个语言的按钮仍链接到 `#solutions`。
- 在生产页面逐一检查三个语言的桌面布局。
