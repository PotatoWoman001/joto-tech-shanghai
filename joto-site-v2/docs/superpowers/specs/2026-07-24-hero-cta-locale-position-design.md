# 三语言首页主视觉按钮位置设计

## 目标

将首页“查看解决方案”按钮移到用户标注的主标题旁边空档，使按钮与大标题形成一个视觉组合。

## 位置规则

- 英文桌面端：按钮放在第二行 `Happen.` 右侧空档。
- 中文桌面端：按钮放在“真正发生。”右侧空档。
- 波斯语桌面端：按照 RTL 阅读方向，按钮放在第二行标题左侧空档，并与标题文字保持明确间距，不得覆盖任何字形。
- 小于桌面断点时：按钮继续放在说明文字下方，避免遮挡标题或缩窄正文。

## 实现方式

在主标题外增加相对定位容器。英文和中文桌面按钮继续在标题容器内按比例定位。波斯语标题采用 RTL 右对齐，因此按钮改为锚定完整主视觉内容区的左缘，而不是按 RTL 标题容器宽度计算百分比；这样在宽屏下按钮始终位于标题外侧。移动端保留当前文案列中的按钮。两个按钮使用同一文案、链接和视觉样式，仅通过响应式显示类保证任一视口只显示一个。

不改变主标题文字、动态词、说明文案、背景、信息卡或 CTA 样式。

## 验证

- 英文与中文桌面按钮使用标题容器约 `47%` 的水平位置。
- 波斯语桌面按钮使用完整主视觉内容区的左缘 `left: 0`，不再使用标题容器的 `32%` 水平位置。
- 在 `1916px` 宽屏下，波斯语按钮与第二行标题不得发生水平和垂直交叠。
- 桌面按钮隐藏于移动端，移动按钮隐藏于桌面端。
- 三个语言的按钮仍链接到 `#solutions`。
- 在生产页面逐一检查三个语言的桌面布局。
