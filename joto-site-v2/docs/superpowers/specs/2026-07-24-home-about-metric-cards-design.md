# 首页 About 指标卡重排设计

## 目标

将首页 “WHY JOTO / 选择 JOTO” 区块从上下分离的文字与横向统计表，重排为左侧品牌叙事、右侧四张纵向圆角指标卡的双栏结构，并同步适配英文、中文与波斯语。

## 已确认设计

- 桌面端左侧集中显示区块标签、标题、公司简介与交付说明，整体向页面左侧移动。
- 桌面端右侧纵向排列四张圆角指标卡，卡片参考用户提供的黑底细描边样式。
- 卡片先显示说明文字，再显示指标值；指标值使用 JOTO 主题绿色。
- 四张卡片使用轻微绿色光晕、悬停边框变化和已有的逐项 Reveal 动效，不增加无关内容。
- 平板与手机端改为自然单栏；指标卡保持可读，不出现横向溢出。
- 英文、中文、波斯语共用同一组件结构和既有翻译数据；波斯语继续继承 RTL 排版方向。

## 验收标准

- 首页 About 区块在桌面端呈现明确的左右两栏。
- 四项统计不再独立占据区块下方整行。
- “全生命周期”、`MULTI-VENDOR` 与波斯语长文本不换行溢出卡片。
- `/`、`/zh/`、`/fa/` 都显示相同结构及各自语言内容。
- 项目测试与生产构建通过。
