# JOTO v2 content sources

This file records the sources used for the first English homepage content layer. It is not a certification register.

## JOTO-provided source material

- The supplied `/Users/cuihua/Downloads/joto-site-main/` project was used for JOTO company, service, case-study, location and contact material.
- The approved design specification was used for the exact navigation, hero copy, solution catalogue and partnership levels.
- Partnership levels have **not** been independently verified. The first public release should confirm level wording and current validity with each vendor.
- Case-study wording has been shortened and made deliberately cautious. Client approval and precise project scope should be reviewed before public launch.
- Office addresses, global delivery coverage, phone numbers and the contact email should receive a final operational check before launch.
