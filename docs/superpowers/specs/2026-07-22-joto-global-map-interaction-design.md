# JOTO Global Presence 地图点位与交互设计

日期：2026-07-22
状态：用户已批准

## 目标

保留现有深绿色世界地图底图和 `24×7` 信息，修复荧光点纵向偏移问题，并让地图具备轻量、可查看、不过度抢眼的互动效果。右侧国家列表缩窄，为地图提供更多横向空间。

## 已确认方案

- 不接入 Mapbox、Leaflet 或在线地图瓦片，不改变现有地图视觉形式。
- 点位使用城市真实经纬度，经统一投影函数换算为底图百分比坐标。
- 修复现有纵坐标被二次换算的问题；SVG 路径与 HTML 点位统一使用 `0–100` 百分比坐标系。
- 中国采用三个可视标记：北京独立点、上海与苏州组成长三角聚合点、深圳与香港组成大湾区聚合点。
- 美国的 Cupertino 与 Sheridan 距离足够远，分别显示。
- 东京、曼谷、新加坡、伦敦分别显示独立点。
- 聚合点显示城市数量，悬停或键盘聚焦时展示包含的城市名称。
- 右侧国家项目悬停或聚焦时，高亮该国家的全部标记和路线。
- 标记拥有呼吸光圈，路线使用低强度流动虚线；地图在桌面端跟随指针做不超过数像素的轻微位移和缩放。
- `prefers-reduced-motion` 下停止呼吸、路线流动与指针跟随。
- 桌面布局由地图/列表 `7/5` 调整为 `8/4`；移动端继续上下排列。

## 数据与投影

投影采用与当前完整世界底图匹配的等距圆柱百分比换算：

```text
x = (longitude + 180) / 360 × 100
y = (90 - latitude) / 180 × 100
```

点位数据集中存放在地图模块中，包含标识、国家、城市、纬度、经度和聚合信息。坐标参考 GeoNames 等公开地理数据，运行时不发送第三方地图请求。

## 交互与可访问性

- 地图点使用可聚焦按钮，不使用纯装饰 `span`。
- 每个点具有明确的 `aria-label`；聚合点说明包含的城市。
- 鼠标悬停、键盘聚焦和右侧国家列表均能触发相同高亮状态。
- 信息浮层不得被地图边缘裁切，也不依赖颜色单独表达状态。
- 指针跟随只移动底图、路线和点位组成的统一画布，避免点与地形错位。

## 验收

- 北京、长三角、大湾区、东京、曼谷、新加坡、Cupertino、Sheridan、伦敦均落在正确陆地区域。
- 上海/苏州、深圳/香港不会因强行分开而产生虚假地理距离。
- 国家列表联动、点位浮层、键盘聚焦和减少动态效果模式可用。
- 1440px 与 390px 视口无横向溢出。
- 现有 `24×7` 内容、标题和国家列表文案保持不变。
