# Global Presence 横向节点卡设计

## 目标

优化 Global Presence 中六个国家的横向信息栏，使其更有地域识别、空间层次与轻盈动感，同时保持 JOTO 企业级暗色视觉，不引入旅游宣传式的写实地标或国旗。

## 方案比较

1. **只增加漂浮动画**：改动最小，但六栏依然缺少地域识别，静止截图仍显单调。
2. **使用写实地标插画**：地域感最强，但会抢夺世界地图的视觉主角，并使页面更像旅游或地产网站。
3. **抽象地域图标与微动效节点卡（采用）**：用统一线性图标表达地域气质，以错峰漂浮、能量线和地图联动增加生命力，在辨识度与专业感之间最平衡。

## 布局

- 世界地图保持完整宽度，六个节点卡排列在地图下方。
- 桌面端为六列，平板端为三列或两列，手机端为单列。
- 卡片使用 `gap-px` 形成轻薄分隔，不重复堆叠边框。
- 每张卡包含：抽象地域图标、地点数量、国家名称、城市列表。

## 地域图标

- China：城市建筑轮廓，强调本地执行网络。
- Japan：山形轮廓，抽象呼应富士山。
- Thailand：建筑/文化场所轮廓。
- Singapore：水波轮廓，呼应滨海城市。
- United States：通信塔轮廓，强调跨区域连接。
- United Kingdom：时钟轮廓，抽象呼应伦敦城市意象。

图标统一使用 Lucide 线性图标，不使用国旗、照片或写实插画。

## 动效与交互

- 图标圆形节点以 5–7 秒周期进行 3–5px 的低幅上下漂浮，每张卡错开动画延迟。
- 卡片顶部能量线在 hover/focus/地图联动状态下由灰白渐变为 JOTO 绿色并轻微延展。
- hover/focus 时出现局部径向绿色光晕，图标节点轻微放大，文字对比度提高。
- 卡片继续通过稳定的英文 region key 与地图联动；显示文本可随英文、简中、波斯语本地化。
- `prefers-reduced-motion: reduce` 时关闭漂浮和位移动画，仅保留颜色反馈。

## 可访问性与验证

- 六张卡保留原生 `button`，支持键盘 focus，并以 `aria-pressed` 表示联动状态。
- 图标为装饰性内容，使用 `aria-hidden`；国家与城市文本提供可访问名称。
