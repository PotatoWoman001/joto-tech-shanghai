# JOTO V2 导航与 Solutions 网格跟进设计

日期：2026-07-22

## 目标

根据本地预览截图修正 Hero 信息顺序、Solutions 卡片在中等桌面宽度下的不平衡，以及桌面 Solutions 下拉菜单难以进入的问题。

## 方案比较

1. **响应式五列与跨行兜底（采用）**：1024px 以上使用五列；768–1023px 使用双列，并让 Safeguarding 横跨整行。所有常用宽度都保持平衡，且不新增虚构分类。
2. **Safeguarding 横向特色卡**：保持双列更久，将最后一张做成特殊横向卡。强调度更高，但破坏五类服务的一致性。
3. **增加第六分类**：形成完整的 2×3 网格，但没有真实业务内容，不采用。

## 最终设计

### Hero

- 将主标题 `BUILD WHAT'S NEXT.` 放在绿色眉题 `ENTERPRISE-READY IT SOLUTIONS` 上方。
- CTA、说明文字和玻璃信息卡位置保持不变。

### Solutions 网格

- 768–1023px：两列布局，Safeguarding 横跨两列。
- 1024px 及以上：五列等宽布局，Safeguarding 恢复单列。
- 767px 及以下：维持单列布局。

### 桌面 Solutions 菜单

- 将桌面 `SOLUTIONS` 入口改为可点击按钮，并使用 `aria-expanded` 表达状态。
- 点击或悬停可打开目录；鼠标从入口向下移动时，透明连接区域持续接收指针，避免下拉层消失。
- 鼠标离开菜单区域、按 Escape 或点击目录链接后关闭。
- 删除 `SOLUTIONS / CATEGORY / VENDOR` 绿色说明行，目录直接从五个分类开始。
- 手机导航行为保持不变。

## 验收标准

- 1024px 以上五张服务卡同排；768–1023px 最后一张横跨整行。
- Hero 主标题显示在绿色眉题上方。
- 桌面 Solutions 入口可点击打开，鼠标能够稳定移入目录。
- 目录中不再出现 `SOLUTIONS / CATEGORY / VENDOR`。
- 现有测试、生产构建和 1024px/1440px 浏览器验证通过。
