# JOTO V2 视觉修订设计

日期：2026-07-22

## 目标

在不改变现有单页架构、导航命名和 Solution 品牌层级的前提下，提高首屏信息密度、服务分类辨识度、案例区视觉一致性与全球业务表达，并消除所有可见文字溢出。

## 方案比较

1. **原创分类视觉（采用）**：为五类服务分别制作统一风格的深色科技图片，并制作同风格世界地图。分类最清晰，整体感最强。
2. **单图重复裁切**：复用一张科技图片，通过不同裁切和蒙层区分类别。开发较快，但五类服务辨识度有限。
3. **纯图标与 CSS 图形**：不增加图片资源。加载最轻，但无法达到用户要求的直观视觉呈现。

## 最终设计

### 1. Hero 首屏

- 将原有小号说明文字从标题下方移出。
- 在首屏中左部空白区域放置放大后的品牌主张，桌面端使用约 32–44px 的响应式字号，限制最大宽度。
- 保留现有视频、渐变、网格、玻璃卡片、主标题和 CTA。
- 移动端恢复紧凑排版，避免主张与玻璃卡、标题重叠。

### 2. Solutions 服务分类

- 保留 Network、Security、Server & Storage、Collaboration、Safeguarding 五个分类。
- 删除分类卡片内的品牌列表和合作等级。
- 每张卡片增加一张独立的 16:10 深色科技图片，分别表达网络、安全、服务器与存储、协作通信、实体安防。
- 图片不含品牌、文字或人物，统一使用黑色、墨绿色和青绿色光效。
- `SOLUTIONS → 分类 → 品牌` 的桌面与手机导航层级继续保留，品牌数据不删除。

### 3. Case Studies 案例

- 不增加无关装饰图，改为放大并统一现有客户 Logo 的视觉区域。
- 每张卡片设置一致的 Logo 舞台高度、最大宽度和光学尺寸；不同长宽比的 Logo 单独适配。
- Logo、标题和能力标签保持安全间距，在小屏幕自动换行。

### 4. About 数据卡

- 数据字号改为受卡片宽度约束的响应式 `clamp()`。
- 为长词增加专门缩放规则，并设置 `min-width: 0`、安全换行和溢出保护。
- 全站检查标题、标签、按钮及卡片文案，确保桌面和手机端均不出框。

### 5. Technology Portfolio

- 从页面中完整移除该区块。
- 合作品牌数据继续供 Solution 导航使用，不删除内容源。
- 后续区块编号顺延，Global Presence 改为第 05 区。

### 6. Global Presence

- 删除当前雷达圆环图。
- 左侧改为深色世界地图，叠加青绿色业务节点和连接线，突出中国、亚洲、北美与英国的全球覆盖。
- 地图不承载正文，国家和城市仍使用右侧真实 HTML 列表，保证可读性、可维护性和无障碍访问。
- 保留 24×7 服务信息，并与地图形成前后层级。

## 资源与性能

- 新增 5 张分类图和 1 张世界地图图，输出 WebP，保留高分辨率源文件。
- 页面使用响应式尺寸和懒加载；首屏以外图片不阻塞首屏加载。
- 所有生成图片均存入项目本地资源目录，不依赖第三方 CDN。

## 验收标准

- 桌面端 Hero 空白区域得到有效利用，且不遮挡主标题、导航和玻璃卡片。
- Solutions 卡片不再显示品牌列表，五类服务通过图片能被直观区分。
- 四个案例 Logo 视觉大小一致且明显增大。
- `LIFECYCLE` 及全站其他文字在 375px、768px、1440px 宽度下无横向溢出。
- Technology Portfolio 区块不再渲染，但导航中的品牌层级完整保留。
- Global Presence 使用世界地图呈现，地区列表与 24×7 信息保留。
- 构建、自动化测试和浏览器桌面/手机检查全部通过。
