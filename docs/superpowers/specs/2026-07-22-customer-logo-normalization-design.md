# 客户 Logo 墙素材清理与视觉归一化设计

## 背景与目标

当前客户 Logo 墙混用了透明 PNG、带不透明浅色底的 PNG 和 SVG。Bosch、Sennics、常熟农商银行、Saint-Gobain 等素材会在浅灰卡片中显示出额外的白色矩形；同时，各素材原始画布、透明留白和长宽比差异较大，统一使用同一个 `max-height` 与 `max-width` 后，视觉大小仍明显不一致。

本次调整的目标是：移除所有可识别的白色或浅灰背景及多余画布留白，让两行 Logo 在卡片内具有接近的视觉重量，同时保留现有卡片、滚动方式、默认灰度和悬停恢复彩色的交互。

## 方案

采用“素材预处理 + 轻量显示档位”的组合方案。

1. 扫描全部客户 Logo 位图，识别从画布边缘连续延伸的白色或浅灰背景，将其转换为透明区域；不删除 Logo 图形内部被深色边界包围的白色细节。
2. 按透明像素裁掉无效外边距，并保留少量安全边距，避免图形紧贴资源边缘。
3. 保持 SVG 原有矢量质量；仅在 SVG 确实包含整幅背景图层时移除该背景，不改动品牌图形本身。
4. 在客户 Logo 数据中增加可选的视觉尺寸档位。默认档覆盖大多数横向 Logo；宽扁、标准横向、方形或徽章类 Logo 使用少量离散档位，而不是为每个 Logo 写任意像素值。
5. 组件使用统一的内容容器和尺寸档位控制 Logo 的视觉高度与最大宽度。继续保留 `object-contain`、默认灰度、降低亮度和悬停恢复彩色效果。

## 视觉规则

- 卡片尺寸、背景色、圆角、间距及两行滚动方向保持不变。
- 标准横向 Logo 的目标视觉高度约为 32–36px。
- 方形、圆形或徽章类 Logo 的目标视觉高度约为 38–42px。
- 超宽 Logo 以最大宽度为主要约束，避免压迫卡片左右安全区。
- 同一行相邻 Logo 的视觉重量应接近；不要求外接矩形的数学面积完全相等。
- 默认状态继续使用灰度效果；悬停时恢复品牌色，不新增动画或交互。

## 实现边界

本次只调整：

- `src/assets/customer-logos/` 中存在背景或无效留白的素材；
- `src/content/customerLogos.ts` 中的 Logo 展示元数据；
- `src/components/CustomerLogoWall.tsx` 中与尺寸档位相关的样式；
- 对应单元测试和必要的视觉验证截图。

不更改客户名单、排序、卡片数量、滚动速度、页面文案和其他页面区块。

## 异常处理

- 如果自动背景识别可能侵蚀浅色品牌图形，则对该素材使用保守阈值或手工蒙版。
- 如果处理后素材在浅色卡片上缺乏对比度，优先调整该 Logo 的显示档位或滤镜，不添加新的白色底板。
- 图片加载失败时继续显示现有品牌名称回退文本。

## 验证

1. 检查所有客户 Logo 位图的四角与连续背景区域，确认不再存在整块不透明白底或浅灰底。
2. 更新单元测试，验证尺寸档位能够映射到稳定的 CSS 类，同时维持 42 个可访问图片及隐藏的循环副本。
3. 运行完整测试与生产构建。
4. 在 `/preview/customer-logo-wall` 以桌面宽度进行浏览器截图，检查两行 Logo 的背景透明度、视觉高度、左右安全区和悬停状态。
5. 对照用户截图重点复核 Bosch、Sennics、常熟农商银行与 Saint-Gobain。
