# JOTO V2 Hero 文案与响应式位置设计

日期：2026-07-22

## 目标

将 Hero 主标题更新为两行品牌主张，替换说明文案，并减少手机和平板首屏中导航与内容之间的无效空白；桌面端进一步放大标题，同时重新约束说明文案，避开右侧玻璃卡。

## 方案比较

1. **响应式对齐切换（采用）**：手机和平板将内容组垂直居中，桌面端继续底部对齐。适应不同屏幕高度，不依赖固定像素偏移。
2. **固定负位移**：给内容组设置固定 `translateY`。只适配单一截图高度，容易在短屏手机上与导航重叠。
3. **缩短 Hero 高度**：减少 `min-height`。会压缩视频舞台并增加内容裁切风险。

## 最终设计

### 主标题

- 第一行显示 `We Make IT`，其中 `IT` 使用现有衬线字体斜体。
- 第二行显示 `Happen.`，使用稍弱的白色层级，句点保持 JOTO 绿色。
- 标题取消全大写转换，使用响应式字号；手机端约 56px，桌面端最高约 156px。
- 第二行在平板和桌面端轻微缩进，形成参考图中的两行层次。

### 说明文案

- 内容更新为：`Enterprise networks, security, data centers, collaboration and physical safeguarding — designed, built and supported for the world's most demanding companies since 2010.`
- 桌面端位于标题上方，改为较小字号、左对齐，并将宽度限制在内容容器左侧 48%，不遮挡右侧 `SINCE 2010` 玻璃卡。
- 手机和平板继续显示在绿色眉题下方，保证阅读顺序清晰。

### 响应式位置

- 1024px 以下：Hero 内容组改为垂直居中，减少顶部空白。
- 1024px 及以上：保留当前底部对齐、玻璃卡右侧位置和 CTA 位置。
- Hero 继续使用 `min-height: 100svh`，不裁切背景视频。

## 验收标准

- 主标题准确显示两行 `We Make IT / Happen.`，`IT` 为斜体。
- 新说明文案在页面中完整显示。
- 375×812 与 768×900 下内容明显上移，不与 76px 导航重叠。
- 1024×768 下说明文案与右侧玻璃卡不重叠，标题比上一版增大两个字号层级。
- 1168×900 下保持桌面底部构图。
- 页面无横向溢出，测试与生产构建通过。
