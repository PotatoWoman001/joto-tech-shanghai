# Docker Isolation Batch 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `JOTO Sunny Try` 建立独立的 Web、历史联系服务和 Python 内容归档工具容器，固定端口 `5173`、`9000`，并保持现有部署配置与未跟踪文件不变。

**Architecture:** 仓库根目录的 `compose.yaml` 编排三个独立服务。`web` 和 `contact` 使用各自 Node.js 镜像及依赖卷；`archive` 使用 Python 3.12.13 镜像和编译生成的完整依赖锁，仅通过 `tools` profile 按需运行。

**Tech Stack:** Docker Compose、Node.js 24.18.0、Vite、Node Test Runner、Python 3.12.13、pip-tools 7.5.1、pytest

## Global Constraints

- 只修改本计划列出的 Docker、测试、锁文件和说明文件。
- 不修改或暂存现有未跟踪目录 `joto-site-v2/joto-site-v2/` 和 `joto-site-v2/output/`。
- 所有宿主端口只绑定 `127.0.0.1`。
- Web 固定使用 `5173`；联系服务固定使用 `9000`。
- 不读取或写入真实邮件、阿里云、Resend 或统计密钥。
- 联系服务保持历史回滚用途，不把生产代理从 `admin.jotoai.com` 改到本地服务。
- 正常停止不得删除命名卷。

- [ ] **Step 4: 创建三服务 Compose**

Create `compose.yaml`:

```yaml
name: joto-sunny

services:
  web:
    build:
      context: ./joto-site-v2
    init: true
    ports:
      - "127.0.0.1:5173:5173"
    volumes:
      - ./joto-site-v2:/workspace
      - sunny_web_node_modules:/workspace/node_modules
    healthcheck:
      test:
        - CMD
        - node
        - -e
        - "fetch('http://127.0.0.1:5173').then((response) => { if (!response.ok) process.exit(1) }).catch(() => process.exit(1))"
      interval: 5s
      timeout: 3s
      retries: 18
      start_period: 10s

  contact:
    build:
      context: ./joto-site-v2/functions/contact
    init: true
    environment:
      HOST: 0.0.0.0
      PORT: "9000"
      ALLOWED_ORIGINS: http://localhost:5173,http://127.0.0.1:5173
    ports:
      - "127.0.0.1:9000:9000"
    volumes:
      - ./joto-site-v2/functions/contact:/workspace
      - sunny_contact_node_modules:/workspace/node_modules
    healthcheck:
      test:
        - CMD
        - node
        - -e
        - "fetch('http://127.0.0.1:9000/healthz').then((response) => { if (!response.ok) process.exit(1) }).catch(() => process.exit(1))"
      interval: 5s
      timeout: 3s
      retries: 18
      start_period: 10s

  archive:
    profiles: ["tools"]
    build:
      context: .
      dockerfile: Dockerfile.archive
    init: true
    volumes:
      - ./src:/workspace/src:ro
      - ./tests:/workspace/tests:ro
      - ./content-archive:/workspace/content-archive
    command: ["pytest", "-q"]

volumes:
  sunny_web_node_modules:
  sunny_contact_node_modules:
```

### Task 2: Python 内容归档工具锁定

**Files:**

**Interfaces:**
- Consumes: `pyproject.toml` optional dependency group `test`。
- Produces: reproducible Python 3.12.13 archive test image。

- [ ] **Step 1: 使用固定 pip-tools 生成完整锁文件**

Run:

```bash
docker run --rm --user 501:20 -e HOME=/tmp \
  -v "$PWD:/workspace" -w /workspace \
  python:3.12.13-slim-bookworm sh -c \
  'python -m pip install --target /tmp/pip-tools pip-tools==7.5.1 && PYTHONPATH=/tmp/pip-tools python -m piptools compile --extra test --output-file requirements.lock pyproject.toml'
```

Expected: `requirements.lock` contains exact `==` versions for direct and
transitive dependencies and an autogenerated header.

- [ ] **Step 2: 创建 Python 工具镜像**

Create `Dockerfile.archive`:

```dockerfile
FROM python:3.12.13-slim-bookworm

ENV PIP_DISABLE_PIP_VERSION_CHECK=1
ENV PYTHONDONTWRITEBYTECODE=1

WORKDIR /workspace
COPY requirements.lock ./
RUN pip install --no-cache-dir -r requirements.lock

COPY pyproject.toml ./
COPY src ./src
COPY tests ./tests
RUN pip install --no-deps -e .

RUN pytest -q
CMD ["pytest", "-q"]
```

- [ ] **Step 3: 运行完整配置契约**

Run:

```bash

```
